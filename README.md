# Mobigic Assignment Frontend

A responsive React file gallery client for user registration, login, file upload, shared file browsing, and protected downloads. The client connects to the existing API at `http://localhost:1198`.

## Features

- Fixed branded header with responsive mobile navigation.
- Public file gallery with download-code flow.
- Registration, login, logout, and protected dashboard.
- File upload and delete actions for authenticated users.
- Icon-only social and support links in the footer.

## Tech Stack

React, React Router, Sass modules, Axios, React Icons, and Create React App.

## Run locally

```bash
npm install
npm start
```

## Deploy

```bash
npm run build
npm run deploy
```
